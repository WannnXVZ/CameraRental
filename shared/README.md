# Shared Modules - Camera Rental

Direktori untuk berbagi definisi tipe TypeScript, kontrak DTO, dan spesifikasi OpenAPI antar backend dan seluruh klien frontend/mobile.

## 📁 Struktur
* `types/` - Shared TypeScript interfaces & enums yang di-generate atau didefinisikan bersama.
* `openapi/` - Spesifikasi OpenAPI v3 (`openapi.yaml` / `openapi.json`).

# Frontend Customer - Camera Rental

Single Page Application (SPA) untuk pelanggan dan pengunjung platform Camera Rental.

## 📌 Spesifikasi
* **Framework:** React + TypeScript (Vite)
* **Styling & UI:** Tailwind CSS, shadcn/ui, Lucide Icons
* **State & Data Fetching:** TanStack Query (React Query)
* **Form & Validasi:** React Hook Form, Zod
* **Autentikasi:** Cookie sesi Sanctum (`/sanctum/csrf-cookie` + `/api/v1/auth/login`)

## 🚀 Perintah Dasar (Setelah Inisialisasi Fase 1)
```bash
npm install
npm run dev
npm run build
```

# Mobile Customer Application - Camera Rental

Aplikasi mobile Android-first untuk pelanggan Camera Rental.

## 📌 Spesifikasi
* **Framework:** React Native + Expo (TypeScript)
* **Penyimpanan Token:** Expo SecureStore (Sanctum Bearer Token)
* **Notifikasi:** Expo Push Notification (FCM-based)
* **Fitur Utama:**
  * Penelusuran katalog dan cek ketersediaan kamera
  * Keranjang tersinkronisasi server
  * Multi-step checkout
  * Pengambilan foto / galeri untuk dokumen identitas dan bukti bayar
  * Pemantauan status transaksi real-time & deep linking
* **Build Tool:** Expo EAS Build & EAS Submit

## 🚀 Perintah Dasar (Setelah Inisialisasi Fase 1)
```bash
npm install
npx expo start
```

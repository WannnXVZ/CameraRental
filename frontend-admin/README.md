# Frontend Admin Dashboard - Camera Rental

Single Page Application (SPA) khusus pengelola operasional dan administrator Camera Rental.

## 📌 Spesifikasi
* **Framework:** React + TypeScript (Vite)
* **Styling & UI:** Tailwind CSS, shadcn/ui
* **Fitur Utama:**
  * Manajemen Inventaris & Unit Fisik Kamera
  * Verifikasi Dokumen Jaminan & Bukti Pembayaran
  * Manajemen Serah-Terima & Pengantaran Kurir
  * Pemeriksaan Kondisi Pengembalian & Penerbitan Denda
  * Laporan Pendapatan, Transaksi, dan Utilisasi Aset
* **Autentikasi:** Cookie sesi Sanctum Admin (`/api/v1/admin/auth/login`)

## 🚀 Perintah Dasar (Setelah Inisialisasi Fase 1)
```bash
npm install
npm run dev
npm run build
```
